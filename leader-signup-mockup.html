This is a draft of how claiming run leader roles might work on the website, instead of the WhatsApp polls.

Each run is split into roles. You tap to claim a role, and you can see at a glance which roles are still open. More than one of you can claim the same run - that is fine and expected. The aim is simply to make the gaps visible so the front and back do not get left empty.

Have a play, then tell Paul: does this make sense? Would you actually use it? What is missing?

My standing defaults optional - fill a role automatically when no one else has claimed it

Set yourself as a fallback for the front or back of either group, or for jeffing. You can still change your mind on any given week.
